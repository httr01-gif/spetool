# 특수교육 AI 도구함

경산자인학교에서 개발한 특수교육대상학생용 웹 수업자료를 모아 공개하는 사이트입니다.
자료를 바로 실행하고, 파일로 내려받고, 제작 프롬프트를 복사할 수 있습니다.
선생님들이 새 자료를 올리면 관리자 승인을 거쳐 목록에 나타납니다.

## 폴더 구조

| 경로 | 역할 |
|---|---|
| `index.html` | 도구함 메인. 검색, 필터, 상세 보기, 프롬프트 복사, 프롬프트 전체 복사, QR 생성 |
| `tools.json` | 기본 자료 목록과 설명, 프롬프트. **자료를 추가하거나 고칠 때 이 파일만 수정** |
| `apps/` | 자료 원본 HTML 파일 |
| `thumbs/` | 자료별 썸네일 이미지(WebP, 640×400) |
| `upload.html` | 선생님용 자료 올리기 화면 |
| `review.html` | 관리자용 검토 화면. 승인, 보류, 삭제 |
| `api/track.js` | 실행, 내려받기, 프롬프트 복사 이벤트 기록. 화면에는 표시하지 않음 |
| `api/stats.js` | 관리자 전용 집계 조회 |
| `api/upload.js` | 자료 업로드 접수 |
| `api/review.js` | 관리자 검토 처리 |
| `api/community.js` | 승인된 공유 자료 목록 |
| `api/app.js` | 공유 자료 실행 및 내려받기 |
| `api/_store.js` | 저장소 접속 공통 코드 |
| `vercel.json` | 캐시 및 보안 헤더 설정 |

## 1단계. 깃허브에 올리기

1. github.com 로그인 후 오른쪽 위 `+` 버튼에서 `New repository` 선택
2. 이름을 영문 소문자로 입력하고 `Public` 선택, `Create repository` 클릭
3. Code 탭에서 `Add file` → `Upload files`
4. 이 폴더 **안의 내용물 전체**를 끌어다 놓기(폴더 자체가 아니라 안의 파일과 폴더를 선택)
5. 아래 `Commit changes` 클릭

## 2단계. Vercel에 연결하기

1. vercel.com에 깃허브 계정으로 로그인
2. `Add New` → `Project` → 저장소 `Import`
3. Framework Preset은 `Other`로 두고 나머지는 기본값 유지
4. `Deploy` 클릭. 1분 이내에 주소 생성
5. 이후 깃허브에 파일을 수정해 올리면 자동으로 다시 배포됨

## 3단계. 저장소와 열쇠 설정

집계와 업로드 기능은 저장소가 연결되어야 동작합니다. 저장소 하나로 두 기능을 함께 씁니다.

1. Vercel 프로젝트 화면에서 `Storage` 탭 선택
2. `Upstash for Redis` 선택 후 무료 플랜으로 생성하고 프로젝트에 연결
   - 연결하면 `KV_REST_API_URL`, `KV_REST_API_TOKEN` 환경변수가 자동 등록됨
3. `Settings` → `Environment Variables`에서 아래 두 항목을 직접 추가

| 이름 | 값 | 용도 |
|---|---|---|
| `STATS_KEY` | 본인만 아는 문자열 | 집계 조회와 자료 검토 화면 열쇠 |
| `UPLOAD_KEY` | 선생님들과 공유할 문자열 | 자료 올리기 화면 암호 |

4. `Deployments` 탭에서 최신 배포를 `Redeploy`

두 열쇠는 서로 다르게 정하시기 바랍니다. `UPLOAD_KEY`는 여러 선생님이 알게 되고, `STATS_KEY`는 관리자만 알아야 합니다.

## 관리자 화면

| 목적 | 주소 |
|---|---|
| 자료 검토 | `https://주소/review.html` 에서 STATS_KEY 입력 |
| 집계 표로 보기 | `https://주소/api/stats?key=STATS_KEY값&format=html` |
| 집계 전체 누적 | `https://주소/api/stats?key=STATS_KEY값` |
| 집계 특정 날짜 | `https://주소/api/stats?key=STATS_KEY값&day=2026-09-13` |

기록 항목은 `open`(바로 실행), `download`(내려받기), `prompt`(프롬프트 복사) 세 가지입니다.
날짜별 기록은 400일간 보관됩니다.

### 검토 절차

1. 선생님이 `upload.html`에서 자료를 올림
2. `review.html` 확인 대기 목록에 나타남
3. **미리 실행**으로 실제 동작을 확인하고, **HTML 원문 확인**으로 내용을 점검
4. 문제가 없으면 **공개 승인**, 보완이 필요하면 **보류**, 부적절하면 **삭제**
5. 승인한 자료만 도구함 목록에 나타남

승인 전에는 자료 주소를 알아도 열리지 않습니다.

## 4단계. 학교 홈페이지에 붙이기

권장 방식은 **링크 연결**입니다. 학교 홈페이지 메뉴에 바로가기를 만들고 새 창으로 열도록 설정합니다.

홈페이지 안에 끼워 넣어야 한다면 게시글 HTML 편집 화면에서 아래 코드를 사용합니다.

```html
<iframe src="https://주소/"
        style="width:100%;height:900px;border:0"
        title="특수교육 AI 도구함"
        allow="camera; microphone"></iframe>
```

`allow` 속성이 없으면 카메라와 마이크를 쓰는 자료가 동작하지 않습니다.

## 자료 추가하고 고치기

관리자가 직접 넣을 때는 깃허브에 올리는 방식이 가장 안정적입니다.

1. 새 HTML 파일을 `apps/` 폴더에 넣기(파일명은 영문 소문자와 하이픈 사용)
2. 프로그램 첫 화면을 캡처해 가로 세로 16 대 10 비율로 잘라 `thumbs/` 폴더에 같은 이름으로 저장
3. `tools.json`의 `items` 배열에 항목을 하나 추가
4. 깃허브에 올리면 자동 반영

### tools.json 항목 형식

| 항목 | 설명 |
|---|---|
| `id` | 영문 고유 이름. 집계 기준이 되므로 한 번 정하면 바꾸지 않음 |
| `name` | 화면에 보이는 자료명 |
| `file` | `apps/파일명.html`. 파일을 제공하지 않으면 `null` |
| `downloadable` | 실행과 내려받기 버튼 표시 여부 |
| `external` | `true`면 내려받기 버튼을 숨김. `file`에 외부 주소를 넣는 자료용 |
| `subject` `grade` `form` | 필터 기준. 교과, 학년, 형태 |
| `device` | 필요 환경 배열. 예 `["터치","마이크","소리"]` |
| `players` `minutes` | 인원과 소요 시간 |
| `summary` | 카드에 보이는 한 문장 설명 |
| `howto` | 수업 활용 방법 배열. 3줄 권장 |
| `support` | 참여와 지원 방법 설명 |
| `prompt` | 제작 프롬프트 전문 |
| `notice` | 주의 문구. 있을 때만 표시 |
| `thumb` | `thumbs/파일명.webp`. 없으면 `null`이며 안내 문구가 대신 표시됨 |
| `updated` | 갱신일. 최근 30일 이내면 NEW 배지 표시 |

## 업로드 기능 제약

| 항목 | 내용 |
|---|---|
| 파일 형식 | 파일 하나로 동작하는 HTML만 가능 |
| 용량 | 4MB 이하. 더 큰 자료는 관리자에게 직접 전달받아 깃허브에 올리는 방식 권장 |
| 썸네일 | 업로드 자료는 썸네일이 없음. 필요하면 관리자가 `thumbs/`에 추가하고 `tools.json`으로 옮겨 관리 |
| 수정 | 올린 자료를 고치려면 다시 올린 뒤 이전 것을 삭제 |

## 공개 전 확인 사항

| 점검 항목 | 내용 |
|---|---|
| 개인정보 | 학생 얼굴, 이름, 목소리, 활동 결과물이 담긴 자료는 올리지 않음 |
| 실명 | 제작 교사 실명 표기는 본인 동의를 받은 경우에만 유지 |
| 외부 링크 | 외부 서버의 이미지나 스크립트를 쓰는 자료는 배포 후 실제로 보이는지 확인 |
| 저작권 | 상용 글꼴, 캐릭터, 사진을 쓴 자료는 사용 범위 확인 |
| 업로드 자료 | 승인 전 반드시 미리 실행과 HTML 원문 확인을 거칠 것 |
